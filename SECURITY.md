# Security Policy

## Supported versions
Security fixes are provided on the latest `main` branch.

## Reporting a vulnerability
If you believe you have found a security vulnerability, please report it privately.

- Preferred: open a GitHub Security Advisory (if enabled for the repository).
- Otherwise: contact the maintainer at `20203078@office.deu.ac.kr`.

Please include:
- a clear description of the issue
- affected versions/commit hash if known
- reproducible steps or a PoC
- impact assessment (what could be exploited)
